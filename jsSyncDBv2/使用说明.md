# jsSyncDB v2 使用说明

本文以浏览器经典脚本 `dist/JssDB-2.0.js` 为例，介绍如何注册数据模型、定义实体、执行增删改查，以及与同步服务器交换数据。该脚本会在全局对象上提供 `JssDB`。

## 1. 引入脚本并注册模型

先运行 `npm run build` 生成 `dist/JssDB-2.0.js`，再在页面中引入它。每个业务表都要注册列清单；如果需要索引查询，还要注册索引字段和索引类型。模型注册应在创建记录和读取该表之前完成。

```html
<script src="./dist/JssDB-2.0.js"></script>
<script>
  JssDB.dbModelColumn.Note = [
    'title',
    'content',
    'category',
    'updatedAt'
  ];
  JssDB.dbModelIndex.Note = 'title';
  JssDB.dbModelIndexType.Note = 'string';
</script>
```

字段含义：

- `dbModelColumn.Note`：`Note` 表中保存的业务字段。`uuid` 和 `table` 是每条对象都必须带有的公共字段，不需要放进此数组。
- `dbModelIndex.Note`：该表的索引字段。示例使用标题，支持按该字段高效筛选和排序所需的索引组织。
- `dbModelIndexType.Note`：索引值类型。字符串使用 `'string'`，数字使用 `'int'`。

没有查询索引需求时仍应注册 `dbModelColumn`；可不指定自定义索引字段，默认按 `uuid` 建立索引。

## 2. 创建数据库对象并配置服务器

```js
const code = 'demo-user-or-tenant';
const dbName = 'notes-db';
const serviceUrl = 'https://sync.example.com/';

const mySyncDB = new JssDB(code, dbName, serviceUrl);
```

构造参数依次为：

1. `code`：同步命名空间，例如用户、租户或应用分区标识。服务端会将它用于区分数据目录。
2. `dbName`：逻辑数据库名称。
3. `serviceUrl`：同步服务的根地址。传 `https://sync.example.com/`，不要传 `/UploadDBObj` 或 `/DownloadDBObj`；客户端会自动补齐尾部斜杠并拼接接口路径。

需要切换同步命名空间或服务器地址时，可在现有对象上调用：

```js
mySyncDB.setService('another-tenant', 'https://sync-backup.example.com');
```

同一份远端数据的客户端必须使用相同的 `code` 和 `dbName`。本地 IndexedDB 也会按这两个值组合出数据库标识；不要在同一浏览器配置中意外复用相同组合来保存互相独立的数据。

## 3. 定义实体对象

实体必须有非空字符串 `uuid`、已注册的 `table` 名称，以及该模型定义的字段。可使用 `JssDB.tools.uuid()` 生成 UUID：

```js
function createNote(title, content, category) {
  return {
    uuid: JssDB.tools.uuid(),
    table: 'Note',
    title,
    content,
    category,
    updatedAt: Date.now()
  };
}

const firstNote = createNote('同步设计', '记录接口与数据模型', '开发');
```

普通 JavaScript 对象即可，不需要继承特定类。保持 `uuid` 稳定很重要：再次保存相同 `uuid` 会更新原实体，而不是创建另一条记录。

## 4. 新增、修改和删除

`writeObj` 和 `deleteObj` 都返回 Promise，可直接使用 `await`。这两个方法会在本地写入数据并记录同步变更：

```js
// 新增；也可以一次传入对象数组进行批量写入。
await mySyncDB.writeObj(firstNote);

// 修改：保留 uuid 和 table，再传入更新后的完整对象。
const updatedNote = {
  ...firstNote,
  title: '同步设计与使用说明',
  updatedAt: Date.now()
};
await mySyncDB.writeObj(updatedNote);

// 删除。
await mySyncDB.deleteObj(updatedNote);
```

删除时传入带有原 `uuid` 和 `table` 的对象。同步删除会记录删除事件，以便将 tombstone 发送到服务端并传播给其他客户端。

如果仍需使用旧式回调，可在 Promise 方法后附加回调：

```js
await mySyncDB.writeObj(updatedNote, function (result) {
  if (result === -1) {
    console.error('本地写入失败');
  } else {
    console.log('写入完成');
  }
});
```

发生异常时 Promise 仍会 reject；提供回调时，失败分支会以 `-1` 通知回调。因此使用 Promise 的代码也可以通过 `try/catch` 处理错误。

### 只写本地、不参与同步

`writeObjWithoutSync` / `deleteObjWithoutSync` 仅修改本地数据，不生成待上传的同步变更。只适合缓存、设备本地设置等明确不需要同步的数据；需要多端共享的业务记录应使用 `writeObj` / `deleteObj`。

## 5. 查询和读取

按 UUID 读取单条记录：

```js
const note = await mySyncDB.dbReadObj(firstNote.uuid);
if (note.uuid) {
  console.log(note.title, note.content);
}
```

`dbReadObj` 找不到记录时返回空对象 `{}`。按表读取所有记录：

```js
const allNotes = await mySyncDB.dbRead('Note');
```

过滤器格式为 `[字段名, 运算符, 值]`；多个过滤器组成数组，条件之间按 AND 处理。下面查找某分类中的标题前缀匹配记录，并跳过前 10 条、最多读取 20 条：

```js
const notes = await mySyncDB.dbRead(
  'Note',
  [
    ['category', '=', '开发'],
    ['title', 'sw', '同步']
  ],
  10,
  20
);
```

支持的运算符包括：`<`、`<=`、`>`、`>=`、`=`、`bt`（左闭右开区间）、`in`、`con`（包含子串）、`sw`（前缀）、`em`（空值或空字符串）、`ne`（非空）。例如：

```js
const selected = await mySyncDB.dbRead('Note', ['category', 'in', ['开发', '工作']]);
const matching = await mySyncDB.dbRead('Note', ['title', 'con', '设计']);
```

支持旧式回调签名，回调可以放在过滤参数之后：

```js
mySyncDB.dbRead('Note', ['category', '=', '开发'], function (rows) {
  console.log('开发分类记录数:', rows.length);
});
```

## 6. 手动同步

本地增删改完成后，调用 `sync()` 将本地待处理变更上传，并下载服务端的新变更：

```js
try {
  const result = await mySyncDB.sync();

  if (result === 1) {
    console.log('同步成功，没有新的服务端变更');
  } else if (Array.isArray(result)) {
    console.log('同步成功，收到的同步事件数:', result.length);
    for (const event of result) {
      console.log(event.objuuid, event.isDelete, event.fromLocal);
    }
  } else if (result < 0) {
    console.error('同步未完成，状态码:', result);
  }
} catch (error) {
  console.error('同步请求发生异常:', error);
}
```

有变更时返回的事件包含 `objuuid`（业务对象 UUID）、`isDelete`（是否为删除事件）和 `fromLocal`（该事件是否来自本客户端的上传回显）。无新事件时通常返回 `1`；负数表示同步未完成或服务端返回了错误状态。不要将返回值固定当作数组处理。

如果应用需要定时同步，可以启用 `autoSync`。支持 WebSocket 的环境会连接服务端通知端点，连接建立后先下载，服务端有变化时再触发下载；本地待上传数据仍由客户端定时处理。WebSocket 不可用时会退回每秒一次的轮询/长轮询。第二个参数是 WebSocket 重连间隔（秒，默认 30 秒），不是下载轮询周期。页面退出或不再需要同步时调用 `stopAutoSync()`：

```js
mySyncDB.autoSync(function (result) {
  if (Array.isArray(result) && result.length > 0) {
    console.log('自动同步收到事件:', result.length);
  } else if (typeof result === 'number' && result < 0) {
    console.error('自动同步失败:', result);
  }
}, 30);

// 例如在应用关闭或组件销毁时：
mySyncDB.stopAutoSync();
```

`sync()` 是完整的手动同步入口，会先上传本地待同步操作，再下载远端变更；通常不需要分别调用 `upload()` 和 `download()`。

## 7. ESM 用法

在 TypeScript / ESM 项目中，从源码入口导入同步类和模型注册表：

```ts
import {
  DbSync,
  dbModelColumn,
  dbModelIndex,
  dbModelIndexType,
  type DbModelObject
} from './src/index';

type Note = DbModelObject & {
  title: string;
  content: string;
  category: string;
  updatedAt: number;
};

dbModelColumn.Note = ['title', 'content', 'category', 'updatedAt'];
dbModelIndex.Note = 'title';
dbModelIndexType.Note = 'string';

const db = new DbSync('demo-user', 'notes-db', 'https://sync.example.com/');
const note: Note = {
  uuid: crypto.randomUUID(),
  table: 'Note',
  title: 'ESM 示例',
  content: '通过类型描述实体字段',
  category: '开发',
  updatedAt: Date.now()
};

await db.writeObj(note);
const saved = await db.dbReadObj(note.uuid);
await db.sync();
```

源码入口导出了 `DbSync`、模型注册表和相关类型；`dist/JssDB-2.0.module.js` 是构建后的 ESM bundle，可通过 `import` 引入。经典页面或需要兼容旧版全局 API 时使用 `dist/JssDB-2.0.js`。

## 8. 常见注意事项

- 先注册模型，再读写该表。未注册的表对象会被判定为无效对象。
- 修改现有对象时保留其 `uuid` 和 `table`，并通过 `writeObj` 写入。
- 需要同步的操作必须使用 `writeObj` / `deleteObj`；`WithoutSync` 版本不会上传。
- 共享同一远端数据的客户端需使用一致的 `code` 和 `dbName`，并配置相同的服务根地址。
- 服务地址必须指向兼容 jsSyncDB 协议的后端；客户端按协议请求 `UploadDBObj` 和 `DownloadDBObj`。
- 经典 bundle 测试和真实后端集成测试的运行方式见 [README.md](README.md) 中的“测试类型”和“真实服务集成测试”。
